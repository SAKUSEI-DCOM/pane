簡易版パネル開け作成サイト

GitHubへのアップロードはindex.htmlだけで動作します。383種類のギフト一覧・画像をすべてHTMLに内蔵しています。画像フォルダのアップロードは不要です。
既存のindex.htmlをこのファイルで上書きし、Commit changesで保存してください。既存のgiftsフォルダは残したままで問題ありません。
元画像サイズを維持、文字色変更、配信シェア10・20・30・40・50回、ギフトのポイント順選択、進行保存・画像出力・特典演出に対応。

X投稿ボタンは通常のリンクとして投稿画面を別タブで開きます。投稿文に企画名と公開枚数が入ります。画像は「現在の画像を保存」で保存し、Xの投稿画面で添付してください。自動投稿は行いません。
