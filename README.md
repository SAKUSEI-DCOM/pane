簡易版パネル開け作成サイト

GitHubへのアップロードはindex.htmlだけで動作します。404種類のギフト一覧・画像をすべてHTMLに内蔵しています。画像フォルダのアップロードは不要です。
既存のindex.htmlをこのファイルで上書きし、Commit changesで保存してください。既存のgiftsフォルダは残したままで問題ありません。
元画像サイズを維持、文字色変更、配信シェア10・20・30・40・50回、ギフトのポイント順選択、進行保存・画像出力・特典演出に対応。

X投稿ボタンは通常のリンクとして投稿画面を別タブで開きます。投稿文に企画名・公開枚数・進捗率が入ります。画像は「現在の画像を保存」で保存し、Xの投稿画面で添付してください。自動投稿は行いません。

丸・長丸を追加。すき間は隠し、全開時に画像全体を表示。ギフト画像と個数表示は各パネル内の安全な領域に合わせて拡大縮小します。元画像の解像度は変更しません。ギフト画像は一覧の絵と直下の名前を一組として再切り出し。
画像付き共有は対応端末の共有先でXを選択。PCでは画像コピー後Xに貼り付け、またはPNG保存・添付。Xへの完全自動添付・自動投稿は実装していません。

添付スクリーンショットから重複を除く21種類を追加（合計404種類）。ギフト枠内のみ切り出し、配信者の顔・プロフィール画像は含みません。名称の見えない素材には識別名を設定。画像内のポイントで並べ替え。

## 丸・長丸ミックス
丸と長丸の選択を統合。大小の長丸と丸を混ぜ、極端に小さな丸を作らず、近いサイズの丸と長丸を混ぜます。元画像サイズと指定枚数を維持。残る隙間は全開時に公開。旧バックアップの丸・長丸は以前の配置で再開できます。

添付スクリーンショットから既存ギフト115種類の画像を高解像度の切り抜きに差し替えました。顔・プロフィール・配信画面は含めていません。

今回のJPEG添付10枚から、一致する既存ギフト76種類を再抽出して置換。ギフト数・名前・ポイントは変更していません。配信画面を除外した切り抜きのみ収録。

## 表示・デザインの追加
正方形モード、三角形・四角形・五角形・丸・長丸のランダムミックスを追加。ランダムミックスは「配置を再生成」で変更できます。正方形は同じ辺の長さで指定枚数を配置し、余白は全開まで隠します。
パネル表示を条件・ギフトまたは番号に切り替え可能。番号表示でも条件は操作一覧に残ります。
文字はゴシック・丸ゴシック・手書き風・手書き数字・明朝、太さは4段階。手書き風・手書きマーカーは内蔵フォントで端末に依存しません。それ以外の書体は端末の対応フォントにより異なります。参考画像風ボタンで紫背景・黒い手書き番号に変更できます。
デザインは無地・桜・血しぶき・鳥・星。作成前と進行中に変更でき、保存データと出力PNGにも反映します。過去のバックアップは元の配置を保持します。新しい丸・長丸の配置を使う場合は新規作成してください。

手書き表示を改良：日本語の手書きフォント Yomogi（SIL Open Font License 1.1）をHTMLに内蔵。端末の代替フォントを使わず、手書き風・マーカーの両方で日本語と数字の自然な筆跡を表示します。文字のわずかな傾き・高さの揺らぎと4段階のペンの太さを反映。画像出力はフォントの読み込み完了後に行います。
