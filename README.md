# パネルびらき — 公開用プログラム

HTML / CSS / JavaScript とギフト画像だけで動作します。ビルド・サーバープログラム・APIキー・Firebase・ChatGPTへのログインは不要です。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作成します。
2. ZIPを解凍し、`index.html` と `gifts` フォルダー、`.nojekyll` をリポジトリの一番上へアップロードします。ZIP自体をアップロードするのではありません。
   - GitHubの画面では `Add file` → `Upload files` から、解凍したファイル・フォルダーをドラッグして追加します。
   - フォルダー構造は変えず、`gifts` 内の画像と `catalog.json` もすべて含めてください。
3. `Commit changes` で保存します。
4. `Settings` → `Pages` を開きます。
5. `Build and deployment` → `Source` を `Deploy from a branch` に設定します。
6. `Branch` を `main`、フォルダーを `/ (root)` に設定し、`Save` を押します。
7. 公開完了後、Pages画面に表示されるURLを開きます。

HTTPSの静的ホスティング（Netlify、Cloudflare Pages等）でも、同じファイル構成で公開できます。出力フォルダーの中身をそのまま公開ルートに置きます。ルートでもサブディレクトリーでも動く相対パスを使用しています。

## 使い方

1. 隠したい画像を選択し、パネル数（2〜100）・形・色を設定します。
2. 各パネルの条件を手入力するか、「ギフトを選ぶ」から画像と個数を選択します。
3. 「適当に埋める」は、空欄だけをランダムな条件で埋めます。入力済みの条件は保持します。同じ種類のギフトを重複抽選しません。選択済みのギフトも抽選候補から除外します。
   - ギフト合計：10,000 / 15,000 / 20,000 / 25,000 / 30,000pt
   - コメント：300 / 350 / 400 / 450 / 500件
   - スター：15,000 / 20,000 / 25,000 / 30,000個
   - 配信シェア：1 / 3 / 5 / 10回、入室：10 / 20 / 30 / 40 / 50人
   - 個別ギフトの個数は従来どおり1 / 2 / 3 / 5 / 10個です。
4. 必要なら特典名と当たり個数を指定します。合計個数はパネル数以下にしてください。
5. 「パネル開けページを作成」を押します。
6. 達成条件を確認し、「開ける」「閉じる」または画像のパネルをタップして操作します。
7. 現在の画像をPNGで保存できます。端末が対応していれば画像付き共有、未対応の場合は画像を保存してXの投稿画面で添付します。投稿の確定は本人が行います。
8. 「バックアップ保存」のJSONで、画像・パネル配置・ギフト画像・開閉状態・特典割り当てを保存できます。「バックアップから再開」で読み込みます。

## ギフト

- ご提供の一覧画像にある382項目と従来の画像外ギフト1種類を合わせ、383種類の画像選択肢を収録しています。最新のアプリ内一覧との自動同期は行いません。ギフト名は表示文字・意匠をもとにした識別名を含みます。
- 「ギフト一覧・画像を登録」で、限定ギフト・未収録ギフト・オリジナルギフトなどの画像を追加できます。複数画像を一括登録でき、ファイル名が仮のギフト名になります。管理画面から名前を編集できます。
- 追加画像は1枚5MB以内、100件まで。登録時に256px以内へ縮小します。
- 公開サイトにギフトを追加する場合は `gifts/catalog.json` に `{ "id": "一意なID", "name": "表示名", "image": "gifts/画像名.png" }` を追加し、画像を同じフォルダーに置きます。
- 収録画像参照元：https://uyet.jp/media/vliver/iriam-giftlist/ （2025年12月のアプリ掲載画像として紹介されたもの）
- IRIAM創作ガイドライン：https://iriam.com/creation

## 分割と保存

- 四角形は、できるだけ正方形に近い配置を探索し、各パネルの面積を等しくします。
- 三角形は近い面積・形へ分割します。奇数枚では一部に面積差が生じます。
- 五角形はCairo型の凸五角形を基準にします。外周は小さな端の切れ端を隣接パネルへまとめ、面積と形のばらつきを抑えるため、五角形以外の形も含みます。完全な正五角形・同面積にはなりません。
- 作成済みの配置はバックアップに含めます。以前の配置も維持して復元します。
- アップロード画像・登録画像・進行状況は端末のブラウザー（IndexedDB）へ保存され、サイトのサーバーへ送信しません。利用者同士で自動共有・同期されません。
- サイト公開後も、配信者がアップロードした一枚絵やパネルの開閉状況は他の訪問者には公開されません。
- ブラウザーの保存データ削除や別ブラウザーへの変更でデータは引き継がれません。バックアップJSONを保存してください。
- IRIAMのコメント数・スター数・ギフト数などを自動取得するAPI連携はありません。達成確認と開閉は手動です。

## ローカルで確認する

このフォルダーで `python3 -m http.server 8000` を実行し、ブラウザーで `http://localhost:8000/` を開きます。

`index.html` を直接開く方法では、ブラウザーの制限でギフト一覧の読み込みや一部の保存機能が使えない場合があります。

本ツールはIRIAMの非公式補助ツールです。

## 元画像のサイズ
アップロードした一枚絵の縦横ピクセル数を変更せず、同じサイズのPNGで保存します。画面内の見た目だけをCSSで縮小表示します。以前の版で既に縮小して保存されたバックアップは、元画像をアップロードし直す必要があります。収録ギフトは、ご提供のギフト一覧画像と参照元画像に基づいています。

## 全件収録とポイント順
ご提供の一覧画像に掲載された382項目を一通り収録し、以前からある画像外の1種類も保持して、計383種類を選択できます。同じ名前で価格帯・絵柄が異なるものは別種類として残しています。期間限定アイコンも含みます。画像に名称のないものは、キャラクターなどで識別する名前を付けています。

選択画面はポイントの低い順に表示し、画像に個別の値がない項目は価格帯（11〜99pt、300〜398pt、500〜800pt）の下限順で並べます。同じ下限では上限の低い順、同じ価格では画像内の掲載順です。価格帯しか読み取れないものの個別価格は推測していません。

自分で追加したギフトは、管理画面の「ptを設定」でポイントを登録できます。未設定は一覧の最後に表示します。

文字表示：太めのゴシック体。作成画面とパネル画面で文字色を選択でき、PNG・バックアップにも反映されます。配信シェアの自動入力は10・20・30・40・50回。パネル内では「配信」「シェア」「回数」の順に改行します。既存の手入力条件は変更しません。
