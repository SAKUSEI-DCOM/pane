今回の変更
・ランダム設定は、選ばれたギフト画像の読み込み完了後に反映します。読み込みが失敗した場合は確定せず再試行できるようにしました。一度に読む画像数を制限し、作成・PNG保存時にも読み込み完了を待ちます。

・「音符」はスクリーンショット内の水色の背景とピンクの音符の画像に更新。緑の音符画像は採用していません。

使い方・従来の機能

ZIPを展開し、index.htmlをブラウザーで開いてください。
GitHub Pagesではindex.htmlを既存ファイルに上書きしてください。
ギフト405種類・星1〜星5のバッジ画像・手書きフォントをHTMLに内蔵しています。

今回の更新
・今回の画像と重複するギフトを新しい画像に差し替え、未登録のHappy Birthday（ユラミィ）を追加。
・ご提供の大好き／あふれる想い／ハッピーバースデーの大きな画像を採用。
・収録ギフトとバッジの透明部分を白背景に統一。今後追加登録するギフトも白背景で保存します。
・各パネルの「バッジを選ぶ」から星1〜星5を選び、必要個数を設定できます。
・作成後の「バッジの達成状況」に星ごとの獲得累計を入力し、「個数を保存して達成パネルを開く」を押すと条件に達したパネルを開きます。
・星の種類ごとに別判定です。同じ星の複数パネルは共通の累計で判定します（消費方式ではありません）。累計を減らしても開いたパネルは自動では閉じません。
・バッジ個数は手入力です。IRIAMから自動取得する機能はありません。
・バッジ条件・累計・公開状態は進行保存とJSONバックアップに含まれます。旧バックアップは累計0で読み込めます。

従来のパネル形状、特典、番号表示、文字・デザイン設定、画像出力を引き続き利用できます。
特典は同じパネルを開き直しても再抽選されません。
手書きフォントYomogiのライセンスは同梱のYomogi-OFL.txtをご確認ください。
