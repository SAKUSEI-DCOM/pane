追加した機能

・輪郭は256×256のマスクから作成します。元画像の縦横比を維持し、全体を隙間なく分割します。

シルエットの使い方
1. 元画像をアップロードし「シルエット」を選びます。
2. 「人物・動物を自動抽出」を押すか、背景透過PNGなら「透過PNGの輪郭を使う」を押します。
3. 緑で示される範囲を確認します。塗り足す／消しゴムとブラシサイズで修正できます。手動だけで作ることもできます。
4. 被写体の分割数を設定します（総枚数未満）。残りの枚数は背景になります。
5. プレビューを確認して作成します。抽出前の四角形プレビューは仮表示です。
・自動抽出は画像内の主要な被写体を切り抜く方式で、人物・動物以外の物も選ばれることがあります。必ず緑の範囲を確認してください。
・自動抽出の初回は外部のモデル・実行モジュールをダウンロードするため通信が必要です。HTTPSで公開したサイト（GitHub Pages等）での利用を推奨します。端末の性能や通信制限によって失敗する場合は、手動指定または透過PNGを利用してください。
・元画像を変更すると抽出範囲はリセットされます。作成済みパネルの輪郭と公開状態はJSONバックアップに保存されます。

デザイン変更
