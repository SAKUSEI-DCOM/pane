パネル開け作成サイト 更新版

GitHubではZIP内のindex.htmlを既存のindex.htmlへ上書きしてください。404種類のギフト画像と手書きフォントをHTMLに内蔵しているため、画像フォルダのアップロードは不要です。

今回の更新
・添付画像と照合し、既存ギフト183種類の画像とポイントを更新。重複は追加せず全404種類を維持しました。
・ランダムミックスは円の周囲も曲線のパネルで埋め、全面を隙間なく覆います。
・既存の三角形とは別に、形や大きさが異なるランダム三角形を追加。形を再生成できます。
・正方形は中央を正方形、上下左右を長方形で埋めます。4枚以下では長方形で分割します。
・指定枚数と元画像のサイズを維持します。狭いパネルの文字やギフトは内側に収まるよう縮小します。

番号／条件・ギフト表示、書体・太さ・文字色、背景模様、進行保存、画像出力、特典演出に対応。
Xボタンは投稿画面を開きます。画像は保存して投稿画面に添付してください。
手書きフォントYomogiのライセンスは同梱のYomogi-OFL.txtをご確認ください。
